@RikiYuko 这两个问题都记下了，1.0.2 已经发出来（Releases 里下最新的 APK，直接覆盖安装就行）。顺手说下原因和正确姿势：

1）App 里粘贴过去总说"输入完整的链接"
- 面板上那行链接是**被省略号截断显示**的，你在屏幕上选中复制出来的是残链接（结尾带着 `…`）；
- 『复制链接』和『复制令牌』是两回事：令牌是给 Docker / 反向代理环境用的**裸令牌**，不是链接。
- 1.0.2 起：粘贴时会自动忽略换行、零宽字符，也接受不带 `https://` 的链接；如果还是不对，会直接告诉你卡在哪 ——「链接被截断了」「这是配对令牌」「这是局域网地址」「缺 ?pair=」。
- 记住点『**复制链接**』按钮，不要用『复制令牌』。

2）手机浏览器点"继续"提示"暂时无法保存确认状态"
- 这句不是 App 的文案，是 DSH 自己的「预览版说明」弹窗：它要把"已确认"写回电脑，而浏览器**没带上配对 Cookie**。
- 微信/QQ 内置浏览器、无痕模式、手输网址、存书签再打开，都会这样。
- 正确姿势：在聊天里**直接点开**链接（别手输），用系统 Chrome/Edge，关掉无痕和"阻止第三方 Cookie"。
- 或者干脆**直接用配对版 App**：设备凭据存在手机本地，不走浏览器 Cookie，最省事。

另外 README 里补了一张「常见问题」表，包括面板上出现"固定域名同步失败"时怎么办（多半是本机代理没启动，插件请求打不出去）。
